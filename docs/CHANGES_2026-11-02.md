### What the comparison found (2010–2024)
| Inputs | RMSE | RMSE 2018+ | Winner acc. |
| --- | --- | --- | --- |
| lean | 0.108 | 0.084 | 92.1% |
| + generic ballot | 0.103 | 0.077 | 93.0% |
| + incumbency | 0.091 | 0.078 | 94.7% |
| + midterm × president | **0.089** | **0.075** | **95.0%** |

- Approval doesn't help once generic ballot and incumbency are in; the 6 approval
  versions are within noise of each other.
- All six inputs together flip generic ballot negative (overfitting): don't use.
- Incumbency's effect has faded (≈11 vote-share points in 1998–2004, ≈2 since 2018),
  which is why training on 2010+ works better than 1998+.

## 4. Leak-free two-stage evaluation + probability check (≈12:30 PM; copied in ≈6:20 PM)

Built after review feedback, before starting the residual model.

**Problem 1:** `data/processed/baseline_residuals.csv` is out-of-fold, but each residual
came from a baseline fit on all other years. A residual model trained on it and tested on
2024 would have indirectly seen 2024.

**Problem 3:** nothing checked whether the win probabilities are trustworthy.

### New / changed files
| File | Change |
| --- | --- |
| `src/election_prediction/twostage.py` (new) | For each test year: inner residuals from baselines that never saw it; `poll_gap` built from that fold's baseline; baseline fit on the training years; residual model fit on training rows only (so its feature selection / early stopping can't see the test year); sigma from the training years' combined held-out errors; P(D wins) three ways (normal, t, logistic), each fitted on training years only. Prints margin errors, sigma per year, log loss / Brier, calibration table, upset check; saves `data/processed/two_stage_oof.csv`. |
| `tests/test_twostage.py` (new) | 5 tests: scrambling one year's results leaves that year's predictions, sigma and probabilities unchanged; the residual model never receives the test year; `poll_gap` uses the fold's own baseline; no-residual equals the plain baseline; probabilities are valid. |
| `train.py` | Docstring points to `twostage.py`; its sigma line says it's for the baseline alone. |
| `configs/baseline.yaml` | `baseline_residuals` labelled "for looking at misses ONLY". |
| `docs/BASELINE_CHANGES.md` | + section 8 on all of this. |

### Results (baseline only, 2010–2024)
| | |
| --- | --- |
| RMSE / winner accuracy | 0.0891 / 95.0% (unchanged, as expected) |
| sigma per test year | 0.088–0.093 |

| Probability method | Log loss | Brier |
| --- | --- | --- |
| normal | 0.1303 | 0.0379 |
| t (df 5, config) | 0.1303 | 0.0380 |
| logistic | 0.1323 | 0.0388 |

Calibration is very good at the extremes (≤ 5% → 0.9% won; ≥ 95% → 99.5% won). Mild lean
in the middle: Democrats given 20–35% won 33% vs 26% predicted (76 races). Too few to act
on yet.
